# 📊 Ad Ops Dashboard — ศูนย์รวมงานยิงแอด

ระบบรวมงานยิงแอด/บูสต์โพสต์จากทุกแบรนด์มาไว้ที่เดียว **แยกตามแบรนด์ชัดเจน**
ดูได้ว่าวันนี้ต้องยิงอะไร แบรนด์ไหนทำ objective อะไรอยู่ พร้อมไฮไลต์สีและแจ้งเตือนเข้า LINE ทุกเช้า

---

## ▶️ วิธีเปิดใช้งาน

### แบบที่ 1 — ดับเบิลคลิก (ง่ายสุด)
ดับเบิลคลิก **`เริ่มใช้งาน.bat`** → ระบบเปิดเบราว์เซอร์ที่ http://localhost:3200 ให้อัตโนมัติ
(ครั้งแรกติดตั้ง Node.js ก่อน: https://nodejs.org)

### แบบที่ 2 — 🌐 เปิดแบบออนไลน์ (ให้ทีมเข้าจากมือถือ/ที่อื่นได้)
ดับเบิลคลิก **`เปิดออนไลน์.bat`**
- ครั้งแรกจะดาวน์โหลด cloudflared (~55MB) ให้อัตโนมัติ — ฟรี ไม่ต้องสมัครอะไร
- ระบบสร้างลิงก์ `https://....trycloudflare.com` ให้ทีมเปิดจากที่ไหนก็ได้
- ถ้าตั้ง LINE token ไว้ **ลิงก์จะถูกส่งเข้า LINE ให้ทีมเองทุกครั้งที่เปิด**
- ⚠️ ก่อนแชร์ลิงก์ **ตั้ง PIN ก่อน** (แท็บ นำเข้า & ตั้งค่า → ใช้งานออนไลน์) ทุกคนต้องใส่ PIN ถึงเข้าได้
- ลิงก์ใช้ได้ตอนคอมเครื่องนี้เปิดอยู่ และเปลี่ยนใหม่ทุกครั้งที่เปิด (ระบบส่งลิงก์ใหม่เข้า LINE ให้เอง)

### แบบที่ 3 — Docker (รันแยก ไม่ต้องลง Node)
```bash
docker compose up -d        # เปิดระบบ (เบื้องหลัง)
docker compose down         # ปิดระบบ
docker compose run --rm notify   # สั่งส่งแจ้งเตือน LINE ทันที
```
ข้อมูลทั้งหมดเก็บในโฟลเดอร์ `data/` (ไม่หายเมื่อ rebuild)

## 🧭 หน้าจอใช้งาน

| แท็บ | ใช้ทำอะไร |
|---|---|
| **วันนี้** | งานที่ต้องยิงวันนี้ (ไฮไลต์แดง) + งานเลยกำหนด เปลี่ยนสถานะได้ในคลิกเดียว |
| **สัปดาห์นี้** | งานล่วงหน้า 7 วัน แยกรายวัน |
| **ปฏิทิน** | รายเดือน วันที่มีงานขึ้นสี + จุดสีบอกแบรนด์ คลิกดูรายละเอียด |
| **ทั้งหมด** | ตารางงานทั้งหมด ค้นหา/กรอง |
| **แบรนด์** | ภาพรวมแยกแบรนด์: แต่ละแบรนด์มีกี่งาน ยิง obj อะไร งบรวมเท่าไร + จัดการแบรนด์ |
| **ตั้งค่า** | LINE token, เวลาแจ้งเตือน, จัดการลิงก์นำเข้าหลายลิงก์ |

- **แท็บแบรนด์** (แถวบนใต้ชื่อแอป) — กดเลือกแบรนด์ แล้วทุกหน้า (วันนี้/ปฏิทิน/รายการ/แบรนด์) โชว์เฉพาะแบรนด์นั้น ไม่ปนกัน · กด "ทุกแบรนด์" เพื่อดูรวม
- **เอกสาร & ลิงก์ประจำแบรนด์** — ในการ์ดแบรนด์ (แท็บแบรนด์): วางลิงก์ไฟล์ออนไลน์ (Drive/Sheet/Canva) หรือแนบไฟล์จริง (สูงสุด 15MB/ไฟล์ เก็บใน `data/files/`) — รวมบรีฟ, media plan, asset ของแต่ละแบรนด์ไว้ที่เดียว
- **เพิ่มงาน / เพิ่มแบรนด์** — ปุ่มมุมขวาบน / ในแท็บแบรนด์
- **โลโก้แบรนด์** — แท็บแบรนด์ → แก้ไข → เลือกรูปโลโก้ (PNG/JPG/WebP/SVG ระบบย่อรูปให้เอง) จะแสดงแทนจุดสีทั้งการ์ดงานและตาราง (ไฟล์เก็บใน `data/logos/`)
- **ค่าธรรมเนียม (fee)** — กรอก % ค่าฟีต่องาน ระบบคำนวณ "งบรวมค่าฟี" ให้เอง (เช่น งบ 2,000 + ฟี 15% = 2,300) ใช้ในการ์ด/ตาราง/KPI/สรุปแบรนด์
- **ทำซ้ำงาน** — ปุ่ม ⧉ ในตาราง หรือในหน้าต่างแก้ไข คัดลอกงานเป็นสำเนา (ล้างผลจริง รีเซ็ตสถานะ) ไว้เปิดรอบ/คอนเทนต์ใหม่เร็ว ๆ
- **ประวัติสถานะ** — แต่ละงานเก็บ log ว่าสถานะเปลี่ยนเมื่อไร (กางดูในหน้าต่างแก้ไขงาน) ไว้ track ว่างานเดินถึงไหน
- **Export Excel** — ปุ่มในแท็บ "รายการ + KPI" ส่งออกงานที่กรองอยู่เป็นไฟล์ CSV (เปิดใน Excel ได้ ภาษาไทยไม่เพี้ยน) ครบทุกฟิลด์ + KPI แผน/จริง + CPM/CPC/CPE
- **แจ้งเตือน LINE ครบวงจร** — นอกจาก "ต้องยิงวันนี้/เลยกำหนด" ยังเตือน "แอดจบวันนี้ (ไปดูผล)", "งบใช้เกินแผน", และ "พรุ่งนี้เตรียมยิงกี่งาน"
- งานถือว่า "ต้องยิง" จาก **วันเริ่มยิงแอด** (ถ้าไม่มีใช้ **วันโพสต์**)
- **Objective เป็น dropdown ล็อกตัวเลือก** (Awareness, Reach, Traffic, Engagement, Video Views, Lead, Messages, Conversion, Sales, GMV Max, App Promotion, Live Shopping, Boost Post) — กรอกตรงกันทั้งทีม กรองเช็คงานตาม Obj ได้ในแท็บ "รายการ + KPI"
- **KPI ครบทุก objective** — เก็บได้ 9 เมตริก: Impression, Reach, Engagement, Click, Video View, Lead, Message, Conversion, ยอดขาย — ทั้ง "เป้า" และ "ผลจริง" คำนวณต้นทุนต่อผลให้เอง (CPM/CPC/CPL/CPA…) + ROAS เมื่อมียอดขาย · เมตริกหลักของแต่ละ obj มี ⭐ กำกับ

### 💲 วางแผนเป้า KPI จากราคาต่อผลลัพธ์ (Rate Card 3 ชั้น)
ราคาต่อผลลัพธ์มี 3 ชั้น ทับกันจากบนลงล่าง: **ค่ากลาง → ราคาเฉพาะแบรนด์ → ปรับเฉพาะงาน**
1. แท็บ **ตั้งค่า → 💲 ราคาต่อผลลัพธ์**: เลือก "ตั้งราคาสำหรับ:" ก่อน — **ค่ากลาง (ทุกแบรนด์)** หรือ **เลือกแบรนด์** เพื่อตั้งราคาเฉพาะแบรนด์นั้น (ช่องที่เว้นว่างจะใช้ค่ากลาง — แสดงเป็นเลขจาง)
2. เปิดงาน → ปุ่ม **KPI** → กล่อง **"⚡ วางแผนเป้าจากงบ"** ใช้ราคาของแบรนด์งานนั้นก่อน (ถ้าไม่มีใช้ค่ากลาง) มีป้ายบอก "ราคาแบรนด์ X" หรือ "ราคากลาง" คำนวณเป้าให้ (เป้า = งบ ÷ ราคา)
3. กด **"⚡ ใส่เป้าตามนี้"** เติมลงตาราง (แก้ต่อได้รายงาน) · ปรับราคาเฉพาะงานในกล่องได้ · กด **"💾 จำเป็นราคาแบรนด์นี้"** บันทึกราคาที่ปรับเป็นของแบรนด์ (หรือค่ากลางถ้างานไม่ระบุแบรนด์)

### 📈 ROAS / ROI / เป้า ROAS
- ทุกงานคำนวณ **ROAS** (ยอดขาย ÷ เงินที่ใช้จริง, กี่เท่า) และ **ROI** ((ยอดขาย − เงินที่ใช้) ÷ เงินที่ใช้, กำไร %) ให้อัตโนมัติ — โชว์ในกล่อง "📊 ความคุ้มค่า" หน้า KPI และป้ายในการ์ดแบรนด์ (รวมทั้งแบรนด์)
- **เป้า ROAS กำหนดเองได้** — ตั้งใน Rate Card (ค่ากลาง/รายแบรนด์ ช่อง "เป้า ROAS … เท่า") งานที่วัดยอดขาย (Sales/GMV Max/Conversion) จะคำนวณ **เป้ายอดขาย = งบ × ROAS** ให้ และเทียบ ROAS จริง vs เป้า (✓ ถึงเป้า / ต่ำกว่าเป้า)
- ทุกเมตริกไม่บังคับกรอก — ไม่กรอกก็แสดง "–" ไม่พัง

## 📥 นำเข้าจาก Google Sheets (หลายลิงก์ได้)

มี 2 วิธี:

**ก) นำเข้าครั้งเดียว** — ปุ่ม `📥 นำเข้า` มุมขวาบน → วาง CSV หรือใส่ลิงก์ → เลือกแบรนด์

**ข) บันทึกลิงก์ไว้ sync ซ้ำ** (แนะนำ) — แท็บ **ตั้งค่า → ลิงก์นำเข้า**
- เพิ่มได้หลายลิงก์ แต่ละลิงก์ผูกกับแบรนด์ได้
- กด **🔄 sync** ทีละลิงก์ หรือ **🔄 Sync ทุกลิงก์** พร้อมกัน
- เปิด "แทนที่ข้อมูลเก่า" ไว้ = sync ใหม่ทับของเดิมของลิงก์นั้น (กันข้อมูลซ้ำ)

> ระบบจับคู่หัวคอลัมน์อัตโนมัติทั้งไทย/อังกฤษ: `Brand/แบรนด์`, `Content/คอนเทนต์`, `Budget/งบ`, `Start Ads/วันเริ่มยิง`, `Obj/วัตถุประสงค์`, `Status/สถานะ`, `Channel/ช่องทาง`, `Gencode`, `วันโพสต์` ฯลฯ
> ถ้าตารางมีคอลัมน์แบรนด์ ระบบจะสร้างแบรนด์ให้อัตโนมัติ
> วิธีเอาลิงก์ CSV: ใน Google Sheet → `File → Share → Publish to web → เลือกชีต → CSV`

## 🔔 ตั้งค่าแจ้งเตือน LINE (ทำครั้งเดียว)

1. สร้าง LINE Official Account แบบ Messaging API ที่ https://developers.line.biz/console/
2. แท็บ **Messaging API** → ออก **Channel access token (long-lived)** → คัดลอก
3. ในแอป: แท็บ **ตั้งค่า** → วาง token → **บันทึก**
4. ให้ทีมแอดบอทเป็นเพื่อน (สแกน QR ในหน้า Messaging API) — ระบบส่งแบบ broadcast หาเพื่อนทุกคน
5. กด **ทดสอบส่ง LINE ตอนนี้** เพื่อเช็ก

**ให้เตือนเองทุกเช้า (Windows):** เปิด Task Scheduler → Create Basic Task → Daily เวลาเช้า → Action: เลือกไฟล์ **`แจ้งเตือน-LINE.bat`**
> คอมต้องเปิดอยู่ตอนถึงเวลา ระบบถึงจะส่ง (เพราะรันบนเครื่องตัวเอง)

ข้อความที่ส่งจะ **แยกตามแบรนด์ + บอก objective** เช่น:
```
🔴 วันนี้ต้องยิง 2 งาน
🏷️ Thychef
  1. Content 2 แจกเมนู (Facebook) · Engagement · ฿2,000
```

## 🗂️ โครงสร้างโค้ด

```
src/
├── server.js              จุดเริ่มเซิร์ฟเวอร์
├── config.js              ค่าตั้งระดับแอป (อ่าน env ได้)
├── lib/                   ฟังก์ชันบริสุทธิ์ (ทดสอบง่าย ไม่ผูก state)
│   ├── dates.js           แปลง/แสดงวันที่ (รองรับ พ.ศ.)
│   ├── csv.js             parse CSV + จับคู่หัวคอลัมน์
│   ├── taskStatus.js      ตรรกะความเร่งด่วน/ปิดงาน
│   ├── message.js         สร้างข้อความสรุปแยกแบรนด์
│   ├── line.js            ส่ง LINE
│   └── http.js            ตัวช่วย route
├── store/                 ชั้นเก็บข้อมูล (ไฟล์ JSON)
│   ├── jsonStore.js       เขียนไฟล์แบบ atomic
│   ├── brands.js · tasks.js · settings.js
├── services/              ตรรกะธุรกิจ
│   ├── importService.js   นำเข้า/sync หลายลิงก์
│   ├── notifyService.js   สร้าง+ส่งแจ้งเตือน
│   └── taskEnricher.js    แนบข้อมูลแบรนด์ให้งาน
├── routes/                REST API (/api/*)
└── jobs/notify.js         สคริปต์แจ้งเตือนตอนเช้า

public/                    หน้าเว็บ (React ผ่าน CDN — ไม่ต้อง build)
├── index.html
└── js/ utils · components · views · settings · app
```

**แก้ไขง่าย:** แต่ละไฟล์ทำหน้าที่เดียว เพิ่มฟิลด์งาน → แก้ `store/tasks.js` + `public/js/components.js`;
เพิ่ม route → สร้างไฟล์ใน `routes/` แล้ว mount ใน `routes/index.js`

## 🔌 REST API (ย่อ)

| Method | Path | ทำอะไร |
|---|---|---|
| GET/POST/PUT/DELETE | `/api/tasks` | จัดการงาน |
| GET/POST/PUT/DELETE | `/api/brands` | จัดการแบรนด์ |
| POST | `/api/import/text` · `/url` | นำเข้าครั้งเดียว |
| GET/POST/PUT/DELETE | `/api/settings/sources` | จัดการลิงก์นำเข้า |
| POST | `/api/import/sync/:id` · `/sync-all` | sync ลิงก์ |
| GET/PUT | `/api/settings` | ตั้งค่า LINE/เวลา |
| GET/POST | `/api/notify/preview` · `/test` | ดู/ทดสอบแจ้งเตือน |

## ❓ แก้ปัญหา

- **เปิดเว็บไม่ได้** → เช็กว่าหน้าต่างดำ (`เริ่มใช้งาน.bat`) ยังเปิดอยู่

- **สำรองข้อมูล** → คัดลอกโฟลเดอร์ `data/`
